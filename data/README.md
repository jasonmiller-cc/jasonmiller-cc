# Profile data

GitHub renders these CSV files as tables with a built-in **search box**, so you can filter by skill, company, or year.

| File | Contents |
| :-- | :-- |
| [`skills.csv`](skills.csv) | Skills with proficiency, years, and where each was used |
| [`experience.csv`](experience.csv) | Roles, dates, highlights, and stack |
| [`credentials.csv`](credentials.csv) | Certifications, education, and badges |
